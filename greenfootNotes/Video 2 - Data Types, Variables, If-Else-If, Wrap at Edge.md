## Writing Methods 
A method's definition should start with access modifiers such as `public`, `private`, etc. Then the type of data it should return such as `void`. Finally including the name.
``` Java
public void method(){
	// code
}
```
## Variables 
Greenfoot follows Java's convention of variables. Hence its type must be declared.
``` Java
const int constant = 3.14;
String name = "Philip";
float decimal = 0.75;
```
In such way all variables are treated as local within a class, thus must be passed into methods.
